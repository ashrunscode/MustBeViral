# Final UI UX Strategy

## Product Shape

Build a premium command center for repeated marketing operations. Do not make chat the default UI. A command bar can expose actions; the main surface is brand state, recommendations, workflows, approvals, calendar, and reports.

## Required Routes

- `/signup`, `/login`
- `/app/create-workspace`
- `/app/create-brand`
- `/app/brands/:brandId`
- `/app/brands/:brandId/scan`
- `/app/brands/:brandId/intelligence`
- `/app/brands/:brandId/profile`
- `/app/brands/:brandId/target-market`
- `/app/brands/:brandId/calendar`
- `/app/brands/:brandId/approvals`
- `/app/brands/:brandId/media`
- `/app/brands/:brandId/creative`
- `/app/brands/:brandId/dm`
- `/app/brands/:brandId/analytics`
- `/app/brands/:brandId/reports`
- `/app/brands/:brandId/growth`
- `/app/admin`
- billing success/cancel/settings routes

## UI Rules

- No empty dashboards.
- No spinner-only screens.
- Every AI recommendation shows evidence.
- Approval queue is optimized for mobile first.
- Use dense, calm operational UI with neutral base, measured accent colors, Lucide icons, and compact type.
