## Controlled browser reproduction

Local Next fixture mode at `127.0.0.1:3109`, 1440x900 and 390x900. All external requests blocked during capture; no authenticated account or provider used. `browser-baseline-2026-09-09.json` contains measurements and named PNGs contain the rendered evidence. Requests were GET only. Browser fixtures do not certify tenant or provider behavior.

1. **Resource context loss — reproduced.** Open `/studio/campaign/canvas?canvas=<synthetic-uuid>&revision=<synthetic-uuid>`. Every workflow tab href lacks canvas/revision. W1 regression: navigate between canvas, quote, review and receipt, preserve permitted resource identity; reject cross-workspace IDs server-side.
2. **Sentinel entry — source confirmed, authenticated end-to-end unavailable.** `app/studio/continue/page.tsx` defaults authenticated sessions to `campaign`. Access/Skills pass that literal into management clients, while workspace contracts require real identity. The local fixture rendered configuration errors before an authenticated request could occur; this is not proof of the authenticated server error. W1 must resolve a real permitted workspace or offer selection, never substitute the sentinel.
3. **Closed-wallet model — reproduced.** Billing renders Closed enrollment and `$0.00` without a workspace read. `billing/page.tsx` supplies no props and `defaultBillingUsageViewModel` returns a fixture. W1 must fetch ledger-backed values and display unavailable separately from zero.
4. **Styling — original report not reproduced as a missing CSS load.** All inspected pages loaded styles, paper `rgb(250,250,250)`, Geist and 20px card padding; document width did not overflow at either viewport. Billing headings/internal copy still diverge from accepted typography/product language. The original deployed screenshot/session remains needed to diagnose any missing-styles incident; no speculative CSS rewrite was made.
5. **Settings corrupt resume — reproduced and repaired.** Skills/Access/Billing were cast into a campaign-only union. Undefined step label crashed `/studio/continue` at `toLowerCase`. Persist only known campaign steps; validate stored fields and local destination; derive labels from the known step. Malformed or denied storage now recovers safely.
6. **Canvas prevents navigation — reproduced and repaired.** Each render created a new actor object; the collaboration effect reconnected, emitted a new snapshot, and rendered again. Depend on primitive actor fields so real identity changes reconnect while equivalent snapshots do not. Desktop/mobile navigation regression failed before repair and passed after.
7. **Stale golden entry expectation — reproduced and repaired.** The campaign golden still expected `/studio` to open brief directly, while accepted existing entry opens Continue. The test now follows Start campaign brief and retains every brief assertion. Twenty-eight other golden cases passed on the first run.

Focused Vitest: 2 files / 16 tests pass. Resume browser regression: 4/4 pass (desktop/mobile), including historical malformed settings state. Web typecheck passes. Full packet verification and the corrected golden rerun are recorded in the final verification evidence.
