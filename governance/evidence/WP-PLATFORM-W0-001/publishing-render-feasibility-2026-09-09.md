## Evaluation order and decision

Keep **Postiz first**, **Sendible second**, then direct connectors if neither passes. Own tenant/grant/brand knowledge, originals, approval hashes, schedule intent, publication state and reporting semantics in MustBeViral. Do not self-host Postiz or add its database/queue as platform authority during W1. Local foundation work does not depend on selecting a live publisher.

Postiz documents API-key/OAuth access, organization ownership failures and create-post limits of 90/hour self-hosted and 100/hour cloud, with separate plan quotas. Treat these as this date's documented limits, not purchased capacity or measured throughput. [Official API overview](https://docs.postiz.com/public-api/introduction).

It exposes connection OAuth URLs and a refresh parameter. This is a plausible connection/reconnect path; client departure isolation and exact account selection remain untested. [Connection API](https://docs.postiz.com/public-api/integrations/connect).

Create supports draft, immediate and scheduled intent; list returns provider-facing IDs/URLs. The inspected create reference did not establish a caller-supplied idempotency guarantee. An uncertain submission must enter reconciliation before retry. [Create](https://docs.postiz.com/public-api/posts/create), [List](https://docs.postiz.com/public-api/posts/list).

The upload API returns an asset ID/path. This does not establish authenticated read protection, TTL, deletion or scheduled-fetch retention. Never expose a whole private R2 library to satisfy a provider upload. [Upload reference](https://docs.postiz.com/public-api/uploads/upload-file).

Postiz's current repository license is AGPL v3. Deployment/embedding terms and operational ownership require a separate decision; this assessment makes no legal determination about a proposed deployment. [Repository license](https://raw.githubusercontent.com/gitroomhq/postiz-app/main/LICENSE).

Sendible describes integrator API/automation, SSO and client-managed profile connection. That demonstrates an integrator offering, not our entitlement to endpoints or successful use of them. Endpoint contracts, account isolation, pricing, retention, error semantics and quotas remain unavailable in this session. No sales or support message was sent. [Official integrator options](https://www.sendible.com/solutions/software-integrators).

## Rendering approach

Use **source-first deterministic composition** for exact logos, text, prices and CTAs. Keep original images and approved brand version pinned. Generation may propose background/motion, but must not repaint protected identity or claim a packshot was supplied when the driver omitted it.

The inspected Core `master_static` payload composes text from `packshots` and other brief fields. It does not pass the selected original image as reference input. fal's editing endpoint documents required `image_url`; that is a different contract from treating a path as prompt text. Any route change needs catalog, driver schema, quote/limits and fidelity tests, followed by a separately authorized paid trial. [Official fal editing API](https://fal.ai/docs/model-api-reference/image-generation-api/flux-pro-kontext).

Local spike: `composition-proof-1080x1350.png` and `composition-proof-2026-09-09.json` prove a 1080x1350 browser composition with exact original source hashes. Two renders match byte-for-byte on the same pinned Playwright Chromium/host. Text remains an independent layout layer; no provider call, fabricated price or output URL was used. The source media is kept unchanged; its display crop is intentional. Cross-runtime/font determinism, image QA, durable render retries, R2 ingest, video encoding and accounting are not proven.

Selected local implementation direction: a typed, immutable composition document with bounded media placements, text/offer references, dimensions, safe zones, approved font asset identifiers, expected source digests and output MIME. A render adapter consumes only validated local/private material, produces a digest/dimension proof, then registers through existing artifact/lineage handlers. Postgres owns job state and retry identity. The execution-location decision (existing hosted renderer versus an authorized additional executor) remains a W3 feasibility gate; the current Core Worker is not claimed to execute Chromium or FFmpeg.

Before production rendering: pin actual font bytes/licenses and runtime, reject URL/SSRF and SVG-script imports, verify decoded MIME/dimensions/orientation, test upload resume/hash mismatch/cancellation, prove memory/runtime bounds, and compare exact logo/price/CTA fidelity across 1:1, 4:5 and 9:16 outputs. Paid reference generation and video rendering remain disabled pending exact model/cost/environment approval.
