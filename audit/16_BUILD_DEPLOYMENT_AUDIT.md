## Build Blockers

These will block first-build the moment scaffolding lands. Document and pre-empt:

1. **Missing `tsconfig.json`** — pin strict mode, target `es2022`, module `esnext`, `moduleResolution: "bundler"`, `types: ["@cloudflare/workers-types/2023-07-01"]` (or current pinned date).
2. **Missing `vite.config.ts`** — required for Vite SSR + worker entry. Use the template's config; preserve `@react-router/dev` plugin.
3. **Missing `tailwind.config.js` / `postcss.config.js`** — required for Tailwind compilation.
4. **Missing `package-lock.json`** — first `npm install` will resolve `"latest"` deps from `setup.py` template, producing non-reproducible builds. **Replace `"latest"` with pinned versions.**
5. **Missing `.gitignore`** — must exclude `node_modules`, `dist`, `.wrangler`, `.env*`, `coverage`.
6. **Decorator usage** — `@callable()` on `MarketingAgent` requires either TS 5+ with native decorator support OR `experimentalDecorators: true` in `tsconfig`. Choose one, document.
7. **Drizzle config** — `drizzle.config.ts` for D1 dialect; `drizzle/` migrations directory; `drizzle-kit` as dev dep.
8. **Wrangler config errors** — placeholders fail validation at deploy time. Need `scripts/cf-bootstrap.ts` (see audit 05) BEFORE any `wrangler deploy` runs.
