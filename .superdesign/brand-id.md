# MustBeViral Studio — Brand ID

Visual and psychological north star: **lightfield.app** (studied live 2026-07-19: computed styles, copy
architecture, trust devices). This document is the brand's constitution; `brand-detail.md` carries the
full psychological teardown and application rules; `design-system.md` carries the executable tokens.

## Essence

**Quiet authority that spends your money carefully.**

Lightfield's core move — and ours — is confidence through restraint. No gradients shouting, no dark-mode
drama, no marketing perfume. A near-white field, black ink at measured opacities, one reserved accent,
small type set with negative tracking, and copy that states capability as fact. The product looks like
it has nothing to prove because it doesn't.

## Positioning

- **Category:** Agentic creative operations for DTC growth teams.
- **One-liner:** _You brief. Agents produce. You approve every dollar._
- **Oppositional frame** (Lightfield's signature rhetorical device, applied to us):
  "AI creative tools burn credits in a black box and hand you a gallery of guesses.
  MustBeViral quotes the run, shows the lineage, and asks before it spends."
- **Enemy:** the black-box credit burner. **Hero:** the accountable operator.

## Personality (5 axes)

| Axis                  | Position                                                    |
| --------------------- | ----------------------------------------------------------- |
| Loud ↔ Quiet          | Quiet — weight-400 headlines, small type, generous field    |
| Playful ↔ Precise     | Precise — evidence in mono, numbers never rounded           |
| Decorated ↔ Plain     | Plain — ink on paper; decoration is information             |
| Promising ↔ Proving   | Proving — receipts, changelogs, named approvals             |
| Friendly ↔ Respectful | Respectful — assumes buyer sophistication, never hand-holds |

## Voice

Declarative, present tense, zero hedging. Short sentences that carry one fact each. Capability stated
plainly ("Agents produce consistent, reliable work"), never inflated ("revolutionary AI magic").
Money is always specific: "$4.20", never "affordable". Fear named honestly (admin drown, budget burn),
relief delivered structurally (quote, cap, receipt). No exclamation marks. No discount language, ever.

## The one accent

Lightfield's entire page contains a single quiet blue. Ours: **one accent — `#2E6BE6` (working name
"signal blue")** — reserved exclusively for the primary action of the current moment (the Confirm
control, the selected state). Everything else is ink. Status colors (green/amber/red) exist only as
small, text-paired evidence chips — never as decoration.

## Brand behaviors (non-negotiable)

1. **Every spend is named before it happens.** The confirm control carries the amount.
2. **Every output carries its receipt.** Model, price, lineage — in mono, immutable.
3. **Progress is real.** No fake percentages, no theatrical loaders; states are named.
4. **The interface recedes.** The user's campaign — their images, their numbers — is the only hero.
5. **Compliance is visible, quietly.** Trust badges and changelog presence, Lightfield-style, without fanfare.
