# MustBeViral Studio — D0 Model-Catalog Evidence

**Scope:** Canonical source-backed evidence for every model that could be ENABLED for the DTC Meta launch-pack tool. Stack: Supabase + Vercel + Cloudflare Worker, fal-first for image/video, provider-direct for text/LLM (fal hosts no text models). **Launch pack definition:** 3 master statics + 3 adaptations each (= 12 images) + ad copy + one 6–10s 9:16 motion clip. **Economics:** landed cost ≤ $5/usable pack; $8/run hard cap. **All prices retrieved 2026-07-19** from primary sources (fal.ai model/pricing pages, provider official docs) except where flagged SECONDARY (search-surfaced; re-confirm on live page before enable). Today: 2026-07-19.

**Headline finding:** Text and image are rounding errors against the $5 target. **Video is the sole dominant cost line.** Select text on retention/moderation/quality (not price); select image on text-rendering fidelity and flat-vs-per-MP billing; select video on motion quality, 9:16 + duration flexibility, and license/IP safety. No listed model breaches the $5 landed target in any recommended configuration.

## Launch-pack cost scenarios (explicit math vs $5 target / $8 cap)

**Pack = copy (~40K in/15K out) + 12 images (3 masters + 9 adaptations) + one 6–10s 9:16 clip.**

### Premium route (contract launch route — kimi-class text + flux-klein-class image, upgraded)

- **Copy** — kimi-k2.6: 0.04×$0.95 + 0.015×$4.00 = $0.038 + $0.060 = **$0.098**
- **Images** — 3 masters FLUX.2 [pro] @ ~$0.045 = $0.135; 9 adaptations FLUX Kontext [pro] @ $0.04 flat = $0.36 → **$0.495**
- **Video** — Seedance 1.0 Pro 1080p 9:16: **6s $0.88** / **10s $1.46**
- **TOTAL: 6s = $0.098 + $0.495 + $0.88 = $1.47/pack; 10s = $2.05/pack**
- ✅ 6s uses **~29%** of the $5 target; 10s **~41%**. Both far under the $8 cap. Video is 60–71% of spend.

### Economy route (operator "low-cost high-production" mandate)

- **Copy** — kimi-k2.5: 0.04×$0.60 + 0.015×$3.00 = $0.024 + $0.045 = **$0.069** (floor: qwen-flash ~$0.008; deepseek-flash ~$0.010 self-host/ZDR only)
- **Images** — 12× FLUX.2 [klein] 4B base @ ~$0.018 = **$0.216** (schnell drafts ~$0.006/img if pre-approving layouts)
- **Video** — Seedance 1.0 Lite 720p 9:16: **6s $0.23** / **10s $0.39**
- **TOTAL: 6s = $0.069 + $0.216 + $0.23 = $0.52/pack; 10s = $0.68/pack**
- ✅ 6s uses **~10%** of the $5 target — ~9.6× headroom; a full pack fits ~15× inside the $8 cap.

### Sensitivity

- Swapping HERO video to Kling 2.6 Pro sound-on (5s $0.70) → premium ≈ $1.29/pack. Swapping images to Ideogram (3 balanced + 9 turbo = $0.45) is cost-neutral. Even the worst plausible combo (Kimi K3 copy $0.345 + FLUX.2 flex 12×$0.10=$1.20 + Seedance Pro 1080p 10s $1.46) = **$3.01/pack — still under $5.**

## Cross-segment flags (license/retention/moderation failing or gating ad-use)

1. **Retention is the decisive text gate, not price.** Kimi + DeepSeek train on API inputs by default with no opt-out (hard flag for brand briefs); DeepSeek is worst (PRC storage, indefinite, shares with advertisers, no SOC2/HIPAA/ZDR). Qwen (Alibaba, Singapore) is the standout no-train posture.
2. **FLUX dev / Kontext-dev / klein-9B weights are non-commercial** — API-only; never self-host. Only klein-4B, schnell, Qwen Image are self-host-commercial.
3. **SD 3.5** free-commercial only below $1M org revenue — flag for a scaling brand.
4. **fal output URLs are public until expiry** — copy every accepted asset to own R2/Supabase immediately; do not deliver via fal URLs.
5. **Seedance 2.0 legal hold** — use 1.0 Pro/Lite only.
6. **Moderation false-refusals** (regulated verticals: alcohol/supplements/gambling/CBD/provocative voice) — run a refusal-rate test on representative real briefs per model before enabling those categories; build reprompt/alternate-engine fallback for fal 422s.
