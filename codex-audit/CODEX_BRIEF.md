## Non-negotiable guardrails

* Multi-brand from day 1.
* Approval before publish, schedule, export.
* Untrusted scan content (always sanitise).
* SSRF-safe outbound (always `normalizeScanUrl`, manual redirect ≤4 hops).
* Raw-body Stripe webhook verification (`c.req.raw.clone().text()` before JSON parse).
* No unsafe DM automation (rules-only, `requires_approval=1` default).
* Mock-safe AI fallback (never silently bill for unconfigured AI).
* No live charges until Sprint C tests pass + user confirms secret writes.
* No destructive operations without explicit user confirmation:
  - `wrangler deploy` (any env)
  - `wrangler d1 migrations apply --remote` (any env)
  - `wrangler secret put` (any env)
  - `git push --force`, `git reset --hard`
  - Stripe live key activation
  - Resource deletion
* Validation gate green at every commit.
* No fake completeness — mocked features must say "mock"; partial fixes must say "partial".

1. Restate the prompt from `20_NEXT_CLAUDE_CODE_FIX_PROMPTS.md` (or define a new one in the same format) at the top of your output:

```
### Prompt: <title>

```

2. Make the smallest safe patch.
3. Run validation gate.
4. Append to `FIX_LOG.md` with the new run number (Run 8+).
5. If a gate fails for unrelated reasons, document it in `codex-audit/KNOWN_FAILURES.md` (create if missing) and do not hide it.
6. Output the run summary in the format from section 11 of the ship-it prompt — nothing else.
