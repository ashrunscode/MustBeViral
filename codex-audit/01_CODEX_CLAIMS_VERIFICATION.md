## Disputed claims summary

The following Codex claims must be downgraded in any subsequent product communications:

1. **"23-step BrandOnboardingWorkflow"** → Stub. No `step.do()` orchestration exists. Workflow file is 14 lines.
2. **"MarketingAgent callable methods (20)"** → Only 5 routes are wired in the DO; the rest return 501. The 20-method spec is satisfied in name only by route-level helpers calling mock generators.
3. **"Production smoke pass" of brand intelligence / target market / calendar / weekly report / growth / image gen** → Smoke proves the route plumbing returns 200 with mock JSON, not that any AI/Workflow/scheduler subsystem actually executed.
